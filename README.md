# V. Sampath — Developer Portfolio

Responsive developer portfolio built with HTML, CSS, and vanilla JavaScript.

## Files
- `index.html` — content and layout
- `style.css` — responsive styling and animations
- `script.js` — typing animation, project filters, mobile navigation

## Publish using GitHub Pages
1. Create a repository named `portfolio` under `varikuppalasampath-gif`.
2. Upload these three website files to the repository root.
3. Open **Settings → Pages**.
4. Select **Deploy from a branch**, choose `main` and `/(root)`, then save.
5. Expected site URL: `https://varikuppalasampath-gif.github.io/portfolio/`

No build tools or package installation are needed. Before publishing, verify project descriptions, update the LinkedIn URL if needed, and remove any confidential information or technologies you do not want to claim.
